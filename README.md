Initial Setup (Themes & Plugins)

After installing and activating the required themes and plugins, follow the steps below.

1. Themes (Install both)
a. ratehawk-hotel-booking
b. ratehawk-hotel-booking-child

2. Plugins
a. kbizsoft-hotel-booking
b. WooCommerce
c. Woocommerce Stripe Plugin

3. RateHawk Plugin Configuration
There is a RateHawk Plugin Settings option available in the WordPress admin panel.
====
Go to:
Settings → RateHawk Plugin Settings

Here you need to:

a. Enter the RateHawk Live Key
b. Enter the RateHawk Sandbox Key
c. Add the WooCommerce Product ID

4. WooCommerce Setup

You need to set up the default WooCommerce pages such as:

My Account

Install the Stripe plugin for WooCommerce:
https://prnt.sc/EO0yodVGP9eN

5. Enable Check-in / Check-out (Important)
By default, check-in and check-out will be disabled in theme.
To enable them, you must complete the following steps:
Go to Accommodation → Seasons → Add New Season
Set up Rates from the Accommodation section
Generate Accommodation

6. Setup Hotel Search Page
Create a new page in WordPress:
Page name: Hotel Search
Assign the template: Hotel Search Result
Reference:
https://prnt.sc/Y53FEOnC7Mg7

7. Create Booking Page
Create a new page in WordPress:
Page name: Create Booking
Assign the template: Hotel Booking Template
Reference:
https://prnt.sc/78RRIK0fqDJe

8. Thank You Page
Create a Thank You page and assign the Thank You Page Template.
Reference:
https://prnt.sc/ZZV4-MKBInm6
